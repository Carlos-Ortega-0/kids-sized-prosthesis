# Kids Sized Prosthesis

Growth-adaptable pediatric prosthetic hand.
Kids outgrow prostheses fast. This design fixes that.
Swappable hand and socket sizes connect through one universal adapter.

![Render](renders/hero.png)

## Design goals
- Three sizes: Small, Medium, Large
- Sizes based on average hand dimensions at major growth spurts
- One universal adapter fits every hand and socket combination
- Low cost, 3D printable

## Repo layout
| Folder | Contents |
|---|---|
| `cad/fusion` | Fusion 360 source files (.f3d) |
| `cad/step` | STEP exports for any CAD tool |
| `stl/small`, `stl/medium`, `stl/large` | Print-ready parts by size |
| `renders` | Images and photos |
| `docs` | Sizing data, design notes, bill of materials |
| `testing` | Fit tests, print tests, results |
